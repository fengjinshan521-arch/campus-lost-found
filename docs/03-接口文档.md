# 接口文档

- 基础路径：`/api/v1`
- 统一响应：`{ "code": 0, "msg": "success", "data": ... }`，`code != 0` 表示业务失败
- 分页结构：`{ items: [], total, page, pages, per_page, has_prev, has_next }`
- 认证：Flask-Login 会话 Cookie；写操作需携带 `X-CSRFToken`（可从 `GET /api/v1/csrf-token` 或任意响应头获取）
- 错误码：`0` 成功 / `1` 业务失败 / `401` 未登录 / `403` 无权限 / `10` 状态流转非法

### 6.1 图片上传与展示

| 方法 | 路径 | 说明 | 权限 |
|---|---|---|---|
| POST | `/upload` | multipart 表单：`file`（必填）+ `entity_type`（或 `subdir`）+ 可选 `entity_id`；返回 `{url}` | 登录 |
| GET | `/uploads/<subdir>/<filename>` | 静态图片访问 | 公开 |

安全策略：扩展名白名单（png/jpg/jpeg/gif/webp）+ 文件头魔数校验 + 随机重命名 + 5MB 上限 + sha256 留痕（`t_attachment`）。

图片绑定链路：登记招领/寻物时表单直接携带 `images` 文件（multipart），或先 `/upload` 拿 URL 再把 `images: [url]` 放进 JSON——两种方式等价；URL 列表存 `t_found_item.images / t_lost_item.images`（JSON），接口统一以 `image_list` 回显。演示库可用 `python scripts/demo_images.py` 为全部信息自动生成按物品类型绘制的示意图（`--force` 重绘、`--only found|lost`）。

### 6.2 管理员管理 admins（系统管理员专属）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/admin/admins` | 管理账号列表：`kw/role/status/page`，附带 `admin_count`/`staff_count`/`active_admin_count`/`roles` 统计 |
| POST | `/admin/admins` | 新建管理账号：`username/password/role(admin\|staff)/real_name/phone/college` |
| PUT | `/admin/admins/<id>` | 编辑资料与角色：`real_name/phone/college/role/status` |
| POST | `/admin/admins/<id>/password` | 重置密码（无需原密码，走强度策略） |
| POST | `/admin/admins/<id>/status` | 启用/停用 |

约束规则：

1. 仅 `role=admin` 可访问；楼管与学生访问返回 403。
2. 角色只能是 `admin`（系统管理员）或 `staff`（楼管/保卫处）；学生账号不在此处管理。
3. 不能停用、降级或改自己账号的角色 —— 避免管理员把自己锁在门外。
4. 系统始终保留至少一个启用状态的管理员（`UserRepository.count_active_admins()` 保护）。
5. 新建与改密均强制 `check_password_strength`；全部操作写 `manager_create`/`manager_update`/`manager_reset_password` 日志，可用 `/admin/logs/trace?target_type=user&target_id=<id>` 追溯。

## 7. 典型调用示例

```bash
# 1) 获取 CSRF Token（写入 cookie 文件保持会话）
curl -c cookies.txt http://127.0.0.1:5000/api/v1/csrf-token

# 2) 登录
TOKEN=$(curl -s -b cookies.txt -c cookies.txt http://127.0.0.1:5000/api/v1/csrf-token \
  | python -c "import sys,json;print(json.load(sys.stdin)['data']['csrf_token'])")
curl -b cookies.txt -c cookies.txt -X POST http://127.0.0.1:5000/api/v1/auth/login \
  -H "Content-Type: application/json" -H "X-CSRFToken: $TOKEN" \
  -d '{"username":"admin","password":"Admin@12345"}'

# 3) 检索
curl -s "http://127.0.0.1:5000/api/v1/items/found?kw=手机&zone=图书馆&page=1"

# 4) 提交认领
curl -b cookies.txt -X POST http://127.0.0.1:5000/api/v1/claims/create \
  -H "Content-Type: application/json" -H "X-CSRFToken: $TOKEN" \
  -d '{"found_item_id":1,"reason":"黑色保温杯，杯盖有磕碰"}'
```
